Captures of the running game, originally uploaded to the ETHGlobal showcase.

| File | What it shows |
| --- | --- |
| `world.jpg` | Two devots at nightfall, the god's roster with the dollar cost of each one's thinking, the life-theft ledger, and the Mind panel with a real prompt and decision |
| `creation.jpg` | The creation screen: traits, the soul sentence, the fixed stat budget, the derived signature, and the wallet the deposit is paid from |

**No demo video yet.** If you add one, note that GitHub will not play an `.mp4` from a
relative repository link — it renders as a download. To get an inline player, drag the
file into any GitHub issue comment, copy the `user-images.githubusercontent.com` URL it
produces, and use that URL in the README.

Keep new images under about 2 MB; the repository is cloned by anyone who wants to run
the world.
